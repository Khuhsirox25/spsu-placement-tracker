Campus Placement Drive Management System

Design before you code: HLD, ER diagram, LLD with a live business-rule simulator, screens and the error matrix.

🎯 Problem & Requirements

Placement teams juggle spreadsheets, emails and portals, causing duplicate data and missed deadlines. CPDMS gives one place to manage companies, drives and applications.

UserWhat they need to do
Placement AdminCreate companies, create drives, define eligibility, view applicants
StudentView drives, apply and track application status
Placement TeamUpdate selection outcomes and generate reports

🧪 LLD Simulator: Apply to a Drive

Change the inputs and press Apply. The checks run in the same order as the pseudo-code.

function applyToDrive(studentId, driveId):
  validate studentId, driveId
  if student not found       -> ERROR "Student not found"
  if drive not found         -> ERROR "Placement drive not found"
  if today > drive.deadline  -> ERROR "Application deadline has passed"
  if student.cgpa < minCgpa  -> ERROR "You do not meet eligibility criteria"
  if already applied         -> ERROR "You have already applied"
  create application (status = "Applied")
  return SUCCESS "Application submitted successfully"
