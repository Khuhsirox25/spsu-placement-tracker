The four CRUD operations

Every app you use is built on these four actions. They light up below as you use them.

➕

Create

Add a new row to the sheet.

POST · action: create
👀

Read

Fetch rows and display them.

GET · action=read
✏️

Update

Change a row found by its ID.

POST · action: update
🗑️

Delete

Remove a row by its ID.

POST · action: delete
