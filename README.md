# SPSU Placement Tracker

A CRUD-based Campus Placement Tracker built during the SPSU Udaipur Championship.

## Problem Statement
Placement teams often track student details in scattered spreadsheets. This web application manages placement-related student records in one place, with live data stored in Google Sheets.

## Features
- Create student records (name, email, domain, placement status)
- View all records in a table
- Update existing records
- Delete records with a confirmation prompt
- Responsive layout for desktop and mobile
- Success and error messages for every action

## Tech Stack
- HTML, CSS, JavaScript (fetch API, async/await)
- Google Sheets (data storage)
- Google Apps Script (backend API)

## How It Works
Browser UI -> fetch() request -> Google Apps Script Web App -> Google Sheets -> JSON response -> Browser UI
